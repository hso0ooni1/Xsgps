# XsGPS Embed — Android AAR

مكتبة قابلة للدمج داخل تطبيق Android تملك مصدره أو لديك تصريح بتعديله. تضيف زر GPS عائمًا يمكن سحبه **داخل نافذة التطبيق نفسه**، وعند الضغط عليه تفتح لوحة تحتوي على: خريطة تفاعلية، بحث بالإحداثيات واسم المكان، 50 موقعًا محفوظًا، حركة عشوائية ضمن نطاق من 0 إلى 100 متر، تشغيل وإيقاف الموقع التجريبي، وخانة كود Android.

### طريقة الدمج في Android Studio
1. فك الضغط عن حزمة AAR، وضع `xsgpslib-release.aar` داخل `app/libs` في مشروع التطبيق المستضيف.
2. أضف إلى `app/build.gradle`:
```gradle
dependencies { implementation files('libs/xsgpslib-release.aar') }
```
3. بعد `super.onCreate()` في `Application` الخاص بتطبيقك:
```java
import com.xsgps.embed.XsGpsOverlay;
XsGpsOverlay.install(this);
```
أو لإظهار الزر على صفحة واحدة فقط، استدعِ `XsGpsOverlay.attach(this)` في `Activity` بعد `setContentView`.
4. أعد بناء وتوقيع تطبيقك. يدمج Gradle صلاحيات الإنترنت والموقع الدقيق وخدمة Foreground Service تلقائيًا من Manifest المكتبة.
5. فعّل خيارات المطوّر، واختر **التطبيق المستضيف** كتطبيق الموقع الوهمي. افتح التطبيق ومنح الإذن للموقع الدقيق. اضغط على زر GPS العائم.

**الأكواد:** النسخة الاختبارية مفتوحة للاختبار افتراضيًا. بعد نشر تحديث Worker الخاص بأكواد Android، أضف `XsGpsOverlay.requireActivation(true)` في `Application.onCreate`. إعدادات ومواضع المستخدم محفوظة في SharedPreferences الخاص بالتطبيق المستضيف؛ ولا تُرسل المواقع إلى سيرفر الأكواد.

**مهم:** هذا AAR لا يعدّل تطبيقات APK تلقائيًا ولا يحوّل أداة iOS إلى Android hooks. يستخدم Android Mock Location الرسمي، ويمكن لبعض التطبيقات كشف الموقع التجريبي ورفضه. لا يلزم روت أو إذن الظهور فوق التطبيقات، ولا يزيل فحوص سلامة التطبيقات أو بصماتها. إذا لم يكن عندك مصدر التطبيق، تحتاج أداة بناء وتوقيع مخولة لتجميع الملفات داخله. التشغيل الفعلي يتفاوت وفق إصدار Android والتطبيق المستضيف.

المصدر: `android/xsgpslib/` داخل مستودع `hso0ooni1/Xsgps`.
